# 各冊各章教學與命題提醒

> **共用檔**：與 [math-rules.md](math-rules.md) 同一組，兩個 repo 內容逐位元組相同；只改 teach-math-web 的正本，再用 `sync_shared_math.py --write` 覆蓋鏡像。

本檔只放各章特有的範圍與易錯點，通則見 [math-rules.md](math-rules.md)。章節依康軒版國中數學（114 學年入學適用）；採用其他版本時，先核對實際教材範圍再引用。各章的教材頁重點清單屬於 teach-math-web 的網頁索引，不作為考卷或其他教材的固定配比。

## 第1冊

### 1-1 整數的運算

- 相反點記號全題一致（例如 A 的相反點記 A′），不混用新字母；絕對值內的運算不能用一般去括號法搬出負號。
- 負數乘方辨底數、括號與外部負號；運算優先序仍保留底數內部先算的條件。科學記號同時檢查係數範圍與指數方向。
- 數線與溫度圖依 [M6](math-rules.md#m6-圖形比例與量測)；絕對值錯誤公式的特例依 [M2](math-rules.md#m2-數學敘述條件與反例)。

### 1-2 分數的運算

- 質因數分解短除法依本課本除到商為質數；輸入本身是質數時不畫空短除法。GCD 與 LCM 的停除條件不同，三數情形要分別檢查。
- 最大公因數型與最小公倍數型應用依情境辨識，不能只看題目出現「最多」或「最少」。兩數乘積關係不直接套到任意多數。
- 分數運算檢查負號、通分、倒數與約分；錯誤診斷須指出實際出錯的分子或分母。指數律分開同底數乘除、乘方的乘方、積與商的乘方及零次方條件。

### 1-3 一元一次方程式

- 代數式化簡與解方程式是不同任務；配圖不可在尚未教等量關係時把天平當成所有代數操作的通用模型。
- 去括號、分配律、分數形式、移項及等量公理分清；應用題設未知數時說明量與單位，題目所問未必就是 x。
- 「設較小者為 x」是策略而非唯一正解；速率題先寫實際相等的量，解出後檢查正負、整數及情境合理性。

## 第2冊

### 2-1 二元一次聯立方程式

- 二元一次式、方程式與解的概念分清；判斷某數對是否為解、無限多組解及限制下的解各有不同任務。
- 代入消去與加減消去先整理；移項成標準式與去分母不要混成一句口訣。每個消元中間式都要驗算。
- 應用題中的總量、差量及倍數要和比較方向一致；不要印出「甲比乙多負數」。未知數不等於所求量時，最後一步須回讀題目。

### 2-2 直角坐標與二元一次方程式的圖形

- 坐標順序、軸上點與象限分清；點到 x 軸的距離量垂直的 |y|，到 y 軸量 |x|，量尺不得越過目標軸。
- 平移正推與回推分開；由符號運算判象限時注意平方、乘積及原點／軸上特例。
- 直線的截距、通過原點、水平／鉛垂特例、聯立交點與圍成面積分開檢查。由兩點作圖前需確認兩點不同；方程式與圖上點以代入互驗。

### 2-3 比與比例式

- 比、比值與比例式區分表示；等值比化簡、內外項、反求量與比例尺先對應量與單位。
- 正比檢查比值固定，反比檢查乘積固定；一起增加／減少或一增一減不足以判定。先辨固定的是哪個量。
- 康軒 1 下本章未教正比圖形，圖形放在第4冊函數；採用其他版本先核對指定教材。

### 2-4 一元一次不等式

- 至少、至多、不超過等語詞要和不等號、實心／空心端點及數線方向一致。
- 乘除負數要變號，不能把乘除正數的規則無條件沿用；去括號、去分母前後用代入值驗證解集。
- 預算、價目、折扣與人數題解不等式後還要依條件取整及檢查門檻。本版不解連寫兩個不等號的不等式，不把兩個條件的情境整理誤作新增解法範圍。

### 2-5 統計

- 長條圖、直方圖、次數分配折線圖與圓形圖依資料與座標意義辨識；百分率和圓心角要回到同一總人數。
- 次數表平均用值乘次數加總；分組平均使用組中點，和原始資料的精確平均區分。中位數先排序或累加定位，不能直接拿最高次數組代替。
- 組界的包含方式一致；眾數、平均數與中位數分開。量測情境圖須驗起點、方向、終點，畫不準時讓插圖退回情境，數據另用正式圖表呈現。

### 2-6 生活中的幾何

- 垂直、線對稱與正多邊形的條件分清；只有邊等長不足以成為正多邊形，頂點順序不能跳著標。
- 找對稱軸、作對稱點及摺剪後結果須以實際重疊關係核對；斜對稱軸不能只套水平／垂直的目視規則。
- 積木三視圖由位置與遮擋推算，不靠圖片猜數量；移走積木會不會改變某視圖需逐方向計算。

## 第3冊

### 3-1 乘法公式與多項式

- 乘法公式的面積拼圖要符合長度及面積；和平方、差平方、平方差的符號與交叉項分清。
- 多項式先辨項、係數、常數項、次數與同類項；去括號時負號作用到整組。幾何尺寸模型只代表其合法範圍，不能取代一般代數推導。
- 乘除運算可用展開、代值及乘回驗算；除法的商與餘式要回到原式檢查，不以版面整齊略掉必要步驟。

### 3-2 平方根與畢氏定理

- 平方根與算術平方根分清；近似值先定位區間，小數呈現依 [M3](math-rules.md#m3-算式與答案的呈現)。
- 根式乘除、提平方因數、分母有理化與同類根式合併分開；最簡表示及獨立反算依 [M3](math-rules.md#m3-算式與答案的呈現)、[M7](math-rules.md#m7-獨立驗算與邊界)。
- 畢氏定理先找直角與斜邊；求斜邊相加、求股相減。複合圖先找實際三角形；示範數組的審查依 [M5](math-rules.md#m5-防止洩題與照抄原題)。

### 3-3 因式分解

- 提公因式、平方差、完全平方式與十字交乘依式型選用；整組括號當一項時，負號作用範圍要完整。
- 十字交乘分常數正負、首項係數是否為 1；缺 x 項是 0x。列完可行整數因數仍不符時，不硬湊分解。
- 反求係數先比較展開後的對應係數；每個因式分解結果都能乘回原式。紙片拼長方形的面積、邊長與代數式須吻合。

### 3-4 一元二次方程式

- 零乘積性質須先把一邊整理成 0；不可直接把等式兩邊各因式分別判為 0。提 x 不能同除 x 而漏掉零解。
- 配方法係數、常數與兩邊同加量逐步查；公式解保留 a≠0 的前提與整個分母，a 為負數時先處理符號。判別式為負在本單元實數範圍沒有實數解。
- 應用問題分代數解與情境可行解；走道是否扣一次或兩次、未知數藏在哪一段、題目問 x 還是 x² 都須回讀。

### 3-5 統計資料處理

- 相對次數的分母是總次數；由比例反求人數先確認總體與百分率。累積次數與相對累積次數不能混用。
- 次數分配折線圖點在組中點，累積圖點在組上限；用同一張圖時要把橫軸意義交代清楚。
- 本章部分次數表與折線圖是第2冊複習，不重複當成全新概念；命題可測銜接，但需明列目標。

## 第4冊

### 4-1 數列與級數

- 有限幾項不能唯一決定所有後續項；題目要求唯一結果時，須交代等差、等比或明確規則。
- 等差數列第 n 項與前 n 項和分清；求項數檢查整數及首末項，兩端差不等於項數。
- 等比數列先確認固定比及有定義的項；零與負比等情形按指定教材處理。

### 4-2 函數

- 函數須每個允許輸入恰對應一個輸出；多個輸入同一輸出可以，一個輸入多個輸出不行。
- 表格、情境、式子與圖形間互查，先確認定義範圍；常數函數是水平線，一次函數的語詞與係數條件依教材定義。
- 圖上截距、增減與實際收費／時間單位一致；費用情境若有整數、門檻或分段限制，不能任意延伸整條直線。

### 4-3 三角形的基本性質

- 多邊形內外角先查凸性、外角選取及邊數；尺規作圖核對定長、定角及每一步依據。
- 全等 SSS、SAS、ASA、AAS、RHS 要配正確對應；AAA 保形不保大小，SSA 一般不能保證唯一全等。
- 中垂線與角平分線區分性質、判別；到兩點等距與到兩直線等距的結論不同。三角形不等式及邊角關係逐項檢查。

### 4-4 平行與四邊形

- 同位角、內錯角、同側內角先確認截線與角的配對；由平行推角度與由角度判平行是兩個方向。
- 平行四邊形的性質與判別分開，對角線平分、等長、垂直各自能推出什麼需補足假設，不能互換。
- 矩形、菱形、正方形及梯形的分類依教材定義；不要靠圖上看似等長、垂直就加入未給條件。

## 第5冊

### 5-1 相似形

- 連比例對齊共同量；ax=by=cz 和連比互換注意倒數。分段比、整段比、對應邊比不混用。
- 相似先配頂點再找邊；平行推出比例，但不完整的比例未必反推平行。縮放角度不變、面積比為長度比平方。
- 影子、坡度及三角比辨清角、高、斜邊、觀測位置與單位。

### 5-2 圓

- 弧度數、弧長、扇形面積與弓形面積分開；同度數的同心弧半徑不同，弧長不會相同。
- 切線垂直切點半徑；由同一圓外點引切線的切線段長相等。弦心距性質先確認同圓／等圓等條件。
- 圓周角定理先確認頂點在圓上並選對不含頂點的弧；半圓直角、平行弦截弧、內接四邊形對角互補分別驗證。不要把本版未列為教學重點的圓內角加進考試範圍。

### 5-3 幾何與證明

- 舉例不是一般證明；反例可推翻全稱命題。奇偶證明用不同整數參數，不無意假定兩數相同。
- 證明先分析所求，再順推書寫理由；全等、相似、面積及代數轉換逐步附依據。
- 外心到頂點等距、內心到邊等距、重心沿中線分成 2:1；三心位置、面積比與特殊直角情形各自處理。

## 第6冊

### 6-1 二次函數

- 由平移與係數判二次函數圖形時，分清開口方向、寬窄、頂點與對稱軸；標示與坐標要能互相代入。
- 最大／最小值需看開口及允許的 x 範圍；實際投籃、高度與時間情境不等於整個實數定義域。
- 圖形縮放不能讓不同函數看起來錯誤等比例；配圖中的球、軌跡與高度只作情境時，不能暗示未驗證的精確數據。

### 6-2 統計與機率

- 四分位數、中位數、四分位距與盒狀圖依排序及教材規則計算；分組直方圖不能唯一還原組內資料，推精確分位數前先辨資料是否充分。
- 機率先列樣本空間、確認等可能；抽取有無放回、順序、重複結果及事件補集交代清楚。

### 6-3 生活中的立體圖形

- 先分線與線、線與面、面與面；空間不相交還可能歪斜。標題「同時垂直於同一條直線」須連內文的平面／直線對象閱讀；空間兩線都垂直同一線不直接推出平行。
- 柱體分底面、側面、展開圖、體積與表面積；最短距離按題目路徑選展開或畢氏定理，不把表面路徑當空間直線。
- 圓柱展開矩形的一邊對應底圓周長；角錐斜高與錐高不同；圓錐展開弧長等於底圓周長。本節錐體重點是表面積，不依章名自行加考未列出的體積。
