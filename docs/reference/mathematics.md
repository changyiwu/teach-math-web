# 數學、教學與命題重點

[回手冊索引](README.md) · [網頁製作](web-production.md) · [各冊清單](README.md#各冊各章) · [來源對照](sources.md)

適用：數學教學網頁、考卷、題庫、講義與簡報。本檔是跨專案數學與命題規則的唯一正文；明確標為「整理建議」者是本次延伸的使用方式。教材範圍、特定記號及作圖約定仍依使用的版本與專案要求核對。

## M1 先定概念與範圍，再決定呈現或配題

- 用「課本主題／小標 → 例題群 → 檢核與評量 → 章節架構」列概念清單；不要因前一節做六點，下一節也做六點。
- 分開考察「概念不同」與「只是換表示法」；學生解題動作不同、錯誤來源不同時值得拆開。
- 課本沒有例題但在評量單列的觀念不能漏；已在前節學過的技巧不必因本節又出現就當成新觀念。
- 版本範圍要逐節核對；教材版本的特定邊界只記在目標冊別，不能把其他版本的內容直接加入。
- **整理建議：** 出考卷時把概念清單轉成命題藍圖，標示評量目標、配分、題型、難度與認知層次；網站配置另見 [W1](web-production.md#w1-教材分析與頁面結構)，不作段考題數規格。

## M2 數學敘述、條件與反例

| 要查的事 | 審查方式 |
|---|---|
| 特例冒充通則 | 看到「一定、只會、都是、唯一」就查假設與反例；方便的設法要說是策略，不排除其他正確解法。 |
| 條件漏寫 | 定義域、分母不為零、根式可定義條件、幾何位置及單位要完整；約分或同除前確認會不會丟掉零解。 |
| 正反方向混用 | 分開「性質」與「判別」；必要、充分或逆敘述不能憑原定理自動成立。 |
| 平面結論搬到空間 | 補查共面、交點及幾何對象，不將不同空間對象套用同一口訣。 |
| 特例被錯誤否定 | 某組值剛好使兩個錯誤形式結果相同，要說明是特例，再找反例檢查一般命題。 |
| 題意與符號矛盾 | 比較方向、正負號、人數／長度／速率、整數限制與「至少／至多」逐項核對。 |
| 定理套錯對象 | 核對定理的對象、已知條件與對應關係；特定章節的條件查冊別提醒。 |

「條件漏寫」與「平面結論搬到空間」是依各節內容整理的共同審查建議；不能省略到只剩標題口訣。

## M3 算式與答案的呈現

1. 變數、數值、單位及圖上代號一致；同一對象不在不同區塊換名字。
2. 無歧義的首項與最終結果不加冗餘括號；符號相鄰或會改變運算解讀時保留。除數帶係數時加括號，負的被除數也適當括住。例：`(-4√35) ÷ (6√5)`，避免讀成連續除乘。
3. 代入並置相乘時，正數也須保留能辨識乘法的括號或乘號，避免把 `2 × 3` 印成 `23`。
4. 分數化簡、分母正負及分母為 1 分開處理；根式最後檢查根號內無平方因數、分母有理化及係數已約分。
5. 「倒數」的中間步驟若要呈現分子分母互換，應先保留互換後的原形，再另一步約分；不能讓說明和畫面上的數字對不上。
6. 指定四捨五入到某位時，答案保留尾零。
7. 本專案線段及長度採上橫線記法；移用到其他試卷時，先確認其記號規範，不能把未加橫線的所有情境一律判成乘法。
8. 分數、根式、上下標、角度與弧記號必須在最終成品中可讀。網頁用 MathJax／Canvas 元件；Word 的 OMML 與試卷版型另依命題專案技能。

## M4 題目、誘答、答案與解析

- 題幹、選項、答案表與解析中的答案字母一致；搬動選項後三方重查。
- 誘答要對應實際可能的錯法。若宣稱「漏掉括號會算出 X」，就沿那條錯路完整重算，確認真的得到 X。
- 解析需指出哪一步、哪個符號或哪個條件有誤；不能看到錯答案就套一段通用診斷。
- 單選題的選項應避免等價重複或同時成立；**這是本次命題用途的整理建議**，須依實際題型驗證。
- 正解 A／B／C／D 盡量均衡，避免固定位置成為答題線索；平衡答案字母不能取代題目品質。
- 應用題解完回到原題：檢查單位、正負、人數整數、長度非負、門檻取整、價格情境，以及題目要的是未知數本身還是其組合。

## M5 防止示範或提示洩漏答案

評量數值與原教材例題須有區隔，但不能只換數字就假定未洩題。六類撞題的完整判準如下，供網頁、講義、題庫與考卷共用：

| 形式 | 查什麼 | 紙本／考卷如何移用 |
|---|---|---|
| 1. 相同原題 | 示範與評量的數字、式子、情境相同 | 檢查例題、提示框、試卷前言是否直接給出解法與答案。 |
| 2. 可調到同題 | 預設值、滑桿範圍、物件個數、模式 | 改查同份資料、題組提示或前一小題是否直接送出目標答案。 |
| 3. 中間式相同 | 原式不同，整理後卻是相同的目標式 | 比對化簡結果、消元後的式子與已展示步驟。 |
| 4. 候選清單命中 | 可選式子、情境、地標與題目重合 | 查範例表、參考選單與提示圖內的所有項目。 |
| 5. 整理或回顧命中 | 左欄重點、公式說明與核心回顧 | 查同卷附表、補充說明與答案選項是否逐字重現。 |
| 6. 等比例或換單位 | 同一組數整體縮放、單位互換 | 將數組化成最簡比例或統一單位後比較，辨識僅換皮的示範。 |

先調示範，再考慮參數範圍，最後才改正式評量；不可為避題刪掉必教的邊界或觀念。特殊直角三角形或固定圓心角的弓形等題型，形狀本來固定；此時要求正式題數字落在互動範圍外，不機械禁止所有相似數組。

**整理建議：** 題組若有意設計為分步引導，前後小題的依賴可以保留，但應明確視為教學／命題設計；不要把刻意引導與無意洩題混為一談。

## M6 圖形、比例與量測

- 教材若主張長度、面積、數量關係，圖形必須真的符合。成長比較不能任意用對數尺度抹平差距。
- 圖上標示應清楚對應頂點、邊、角與單位。本站頂點及邊長放外側；同一邊有兩種標記時分排，必要時下移圖形避免碰標題；他案仍須避免歧義與碰撞。
- 既有生成配圖的可數物件控制每組 ≤8、組數 ≤3，平放並排或方陣，不疊高；大數改用同構小數。這是生成流程的可驗收構圖限制，不是數學限制。
- 比例不能只靠目視；依題意量長度比、面積比、端點或座標。等分的總數與取用數量逐一數清。
- 本專案數線、溫度刻度條及坐標軸只在正向端畫一個箭頭，負向端平切無箭頭；命題時依目標教材約定一致呈現。箭頭、原點與等距刻度都要可辨識。
- 量測圖先核對「從哪裡量、朝哪裡量、到哪裡停」；距離、斜邊、高、斜高、弧長與角度不能相互替代。
- 操作工具形狀必須能產生圖上的結果。齒輪應咬合且有支撐；天平受力與盤內物件要合理；切割或摺疊前後狀態不能矛盾。
- **整理建議：** 考卷的精確幾何與坐標圖優先用 SVG、向量或可計算繪圖產生；AI 插圖適合情境，但不能承擔無法核對的數量與比例。
- 概念本身沒有可核對幾何，或連兩輪仍畫不出來時，氣氛插圖退回同角色的純情境；提示排除數字、符號、箭頭與文字，不繼續硬套比喻。正式考題所必需的幾何條件則須另用準確圖或題幹交代，不能跟著刪掉。

## M7 獨立驗算與邊界

1. 不只拿原本的解題函式再跑一次。另用代入、展開、反向推回、座標量角／面積或另一套求值器檢驗。
2. 不只檢查答案值；每個等號連接的步驟都應等價，且最後的分數與根式符合呈現要求。
3. 邊界至少涵蓋零、負數、相等、恰達門檻、退化／不存在與情境不成立；按所屬章節選取，不強行套入無關案例。
4. 精確整數／分數與浮點近似分開；有限小數用整數與 10 的次方保存，根式及長度可保留平方值，避免誤差判斷整除、同類根式或幾何相等。
5. **整理建議：** 跨媒介輸出要看最終成品：Word／PDF 方程式、圖形、分頁與符號字形；來源文字正確不能代替成品驗收。
