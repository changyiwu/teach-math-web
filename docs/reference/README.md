# 數學教材與教學網頁參考手冊

本目錄是現行教材製作規範的統一入口。規則按主題各有一份完整正文，其他文件以連結引用；日常建頁不必翻舊 AGENTS、歷史紀錄或各節 QA 尋找通則。

## 日常閱讀路徑

| 任務 | 必讀正文 | 執行流程 |
|---|---|---|
| 新建或修改教學頁 | [網頁製作](web-production.md) ＋ [數學與命題](mathematics.md) ＋ 目標冊別 | 本專案 [製作技能](../../.agents/skills/math-interactive-material/SKILL.md) |
| 考卷、題庫、講義等數學專案 | [數學與命題](mathematics.md) ＋ 目標冊別 | 目標專案自己的命題及成品輸出流程 |
| 處理工具問題或抽取共用引擎 | 正文中指向的 [操作附錄](operations.md) 對應小節 | 只讀當下需要的部分 |
| 查舊編號或決策原因 | [來源對照](sources.md) | 再按需要查歷史 |

開工仍按專案要求讀 [AGENTS.md](../../AGENTS.md) 與 [handoff.md](../../handoff.md)。它們分別處理協作與接續狀態；教材規則不在其中另列副本。實際教材及目標節提示詞是任務素材，不能以這份手冊取代。

## 維護與引用

1. 規則變更只改上表所屬正文；需要別處讀到時加入連結，不複寫規則全文。涉及兩類的原條文可拆為語意與實作兩部分，各自只有一個維護位置。
2. 課本版本／範圍改動時更新目標冊別的人工編輯區，再核對實際教材；不要拿舊頁標題作為新版本課綱。
3. 修改教材重點標題或課程結構後，執行 `python tools/update_reference_catalog.py`；檢查使用 `python tools/update_reference_catalog.py --check`。新增章節時先在相應冊別加章名、章內提醒及對應 BEGIN／END LESSONS 標記。
4. 工具或上游技能的操作方式，以該工具的實際介面為準；本手冊只維護本站的規格。生圖／排字時才載入所指定的外部技能，不必日常全文閱讀。
5. 歷史變更查 [里程碑](../history/project-milestones.md)、Git 或 Obsidian 的 teaching-web/專案工作流程.md；個別生成證據查 ignored 的 comfyui/<小節>/。跨機前先確認該批素材已同步。
6. 跨專案引用可直接提供本目錄的完整位置，選讀對應正文；移到獨立專案時另處理教材頁來源連結與所需工具。Word／PDF、紙張、認知層次、題數及配分依目標專案規範。

出卷引用範本：

> 請先讀 mathematics.md，再讀目標 book-N.md 的章內提醒與概念清單，按本次教材核對範圍並執行 M8。網站的版型、互動配置及部署參數不套用到考卷；命題與輸出格式另按本專案規範。
