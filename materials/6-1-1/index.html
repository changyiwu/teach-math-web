1-1 二次函數的圖形與最大值、最小值

走進一座畫滿噴漆塗鴉的街頭籃球場：投出去的籃球、噴在牆上的弧線、可以推來推去的籃球架，背後都是同一種函數。這一節先認識二次函數，再一步步描繪 \(y = ax^2\)、\(y = ax^2 + k\)、\(y = a(x - h)^2\)、\(y = a(x - h)^2 + k\) 的圖形——它們都是拋物線，只是開口方向、大小與位置不同；最後由頂點讀出與 \(x\) 軸的交點個數、最大值與最小值，並反過來由圖形的特性找出二次函數。

課前暖身漫畫：這一球走的是什麼路線？

阿投在街頭球場連投好幾球都差一點。小弧把投籃過程連拍下來，在塗鴉牆上把籃球每一刻的位置噴成一個個點——連起來不是直線，而是一條左右對稱、有最高點的彎弧。這條弧線，就是這一節要研究的拋物線。

重點 1：二次函數的意義——化簡後 \(x\) 的最高次數是二次

重點整理與敘述

  • 第四冊學過：給定每一個 \(x\)，都恰有一個 \(y\) 與它對應，就說「\(y\) 是 \(x\) 的函數」。\(y = ax + b\)（\(a \ne 0\)）是一次函數，\(y = b\) 是常數函數。
  • 正方形球場邊長 \(x\) 公尺、面積 \(y\) 平方公尺，\(y = x^2\)：邊長一確定，面積就確定，\(y\) 也是 \(x\) 的函數，但它不是一次函數。
  • 經化簡後形如 \(y = ax^2 + bx + c\)（\(a \ne 0\)）的關係式，稱為二次函數。\(b\)、\(c\) 可以是 \(0\)，只有 \(a\) 不能是 \(0\)。
  • 一定要先化簡再判斷：看得到平方不代表是二次函數。例如 \(y = 2(x + 1)^2 - 2x^2\) 展開後 \(x^2\) 項互相抵消，剩下 \(y = 4x + 2\)，是一次函數。
  • 反過來，沒有直接寫出 \(x^2\) 的式子也可能是二次函數：\(y = (x - 4)(x + 1)\) 乘開是 \(x^2 - 3x - 4\)。
KEY POINT・二次函數 化簡後 \(y = ax^2 + bx + c\)，且 \(a \ne 0\)

形成性評量 (二次函數的意義)

Q1. 下列各關係式中，哪一個 \(y\) 是 \(x\) 的二次函數？

解析：答案為 B。\(y = x(6 - x) = -x^2 + 6x\)，化簡後 \(x\) 的最高次數是二次，且 \(x^2\) 項係數 \(-1 \ne 0\)，是二次函數。
A 錯：展開後 \[\begin{aligned} y &= 5x^2 - 20x + 20 - 5x^2 \\ &= -20x + 20 \end{aligned}\] \(x^2\) 項抵消了，是一次函數。
C 錯：是一次函數。
D 錯：是常數函數。

Q2. 已知 \(y = k(x + 5)^2 - 3x^2 + 1\)，若 \(y\) 是 \(x\) 的一次函數，則 \(k\) 是多少？

解析：答案為 D。展開後 \[\begin{aligned} y &= kx^2 + 10kx + 25k \\ &\quad - 3x^2 + 1 \\ &= (k - 3)x^2 + 10kx \\ &\quad + 25k + 1 \end{aligned}\] 要是一次函數，\(x^2\) 項必須消失：\(k - 3 = 0\)，\(k = 3\)；此時一次項係數 \(30 \ne 0\)，\(y = 30x + 76\) 確實是一次函數。
A 錯：\(k = -3\) 時 \(x^2\) 項係數是 \(-6\)，仍是二次函數。
B 錯：\(k = 0\) 時 \(y = -3x^2 + 1\)，是二次函數。
C 錯：\(k = \frac{1}{3}\) 時 \(x^2\) 項係數 \(\frac{1}{3} - 3 \ne 0\)。

重點 2：生活中的二次函數——由情境列出關係式

重點整理與敘述

  • 列式三步驟：設出 \(x\) 代表什麼 → 用 \(x\) 表示其他需要的量 → 依題意寫出 \(y\)。
  • 例：靠著球場的牆，用 \(40\) 公尺的圍網圍出長方形，兩側各 \(x\) 公尺，前面就剩 \((40 - 2x)\) 公尺，面積 \(y = x(40 - 2x) = -2x^2 + 40x\)。
  • 若是四周都用圍網，周長是兩個長加兩個寬，長加寬只有周長的一半：周長 \(40\) 時寬是 \((20 - x)\)，\(y = x(20 - x)\)。
  • 列完式子要化簡，看 \(x\) 的最高次數，才判斷得出是不是二次函數。
  • 情境裡的 \(x\) 有範圍（邊長要大於 \(0\)），但關係式 \(y = -2x^2 + 40x\) 本身是二次函數，接下來我們討論 \(x\) 可以是任意數的情形。
KEY POINT・列式 設 \(x\) → 用 \(x\) 表示其他量 → 寫出 \(y\) → 化簡判斷

選擇「靠牆圍成ㄇ形」或「圍成一圈」，拉動圍網總長與邊長 \(x\)。上方是長方形的形狀，下方把每個整數 \(x\) 對應的面積 \(y\) 描成點——點連起來不是直線。

形成性評量 (生活中的二次函數)

Q3. 一張長方形塗鴉海報的周長是 \(36\) 公分。若海報的長為 \(x\) 公分、面積為 \(y\) 平方公分，下列何者正確？

解析：答案為 A。長加寬是周長的一半 \(18\)，寬是 \((18 - x)\) 公分，面積 \(y = x(18 - x) = -x^2 + 18x\)，化簡後最高次數是二次，是二次函數。
B 錯：把整個周長 \(36\) 當成長加寬。
C 錯：那是靠牆圍成ㄇ形的列法，海報四邊都算在周長裡。
D 錯：式子雖然沒有直接寫出 \(x^2\)，乘開就有 \(-x^2\)，是二次函數。

Q4. 街頭籃球聯賽有 \(x\) 隊參加，每兩隊之間都要比賽 \(2\) 場（在雙方的主場各打一場）。若總共要比 \(y\) 場，下列何者正確？

解析：答案為 C。每一隊都在自己的主場和其他 \((x - 1)\) 隊各打一場，而每一場恰好有一個主隊，所以總場數 \(y = x(x - 1) = x^2 - x\)，是二次函數。
A 錯：那是每兩隊只打一場的場數。
B 錯：每一場被兩隊各算了一次，重複計算。
D 錯：\(2(x - 1)\) 只是其中一隊要打的場數。

重點 3：\(y = ax^2\) 的圖形——\(a\) 的正負決定開口方向

重點整理與敘述

  • 描圖：列出一些 \(x\) 與對應的 \(y\)，描點後用平滑曲線連起來。點描得愈多，愈看得出是一條平滑的曲線。
  • \(y = x^2\) 中，互為相反數的 \(x\) 代入得到相同的 \(y\)：\((2, 4)\) 與 \((-2, 4)\) 對稱於 \(y\) 軸。所以圖形是以 \(y\) 軸（\(x = 0\)）為對稱軸的線對稱圖形。
  • \(a \gt 0\)：圖形開口向上，原點 \((0, 0)\) 是最低點；\(a \lt 0\)：圖形開口向下，原點是最高點。
  • 小心：看到平方別以為 \(y\) 一定是正的。\(y = -x^2\) 中，\(x = 2\) 時 \(y = -4\)。
  • 把 \(y = ax^2\) 的圖形沿 \(x\) 軸對摺，會和 \(y = -ax^2\) 的圖形重合（每個點 \((x, y)\) 變成 \((x, -y)\)）。

形成性評量 (\(y = ax^2\) 的圖形)

Q5. 關於二次函數 \(y = -\frac{1}{3}x^2\) 的圖形，下列敘述何者正確？

解析：答案為 B。\(a = -\frac{1}{3} \lt 0\)，開口向下；\(y = ax^2\) 的對稱軸都是 \(y\) 軸，原點是最高點。
A 錯：\(a\) 是負數，開口向下。
C 錯：對稱軸是 \(y\) 軸（\(x = 0\)），不是 \(x\) 軸。
D 錯：\(x = 3\) 代入得 \(y = -\frac{1}{3} \times 9 = -3\)，通過的是 \((3, -3)\)；漏了負號才會算成 \(3\)。

Q6. 將 \(y = 5x^2\) 的圖形沿著 \(x\) 軸對摺，會和下列哪一個二次函數的圖形重合？

解析：答案為 D。沿 \(x\) 軸對摺，點 \((x, y)\) 變成 \((x, -y)\)，所以 \(y = 5x^2\) 變成 \(y = -5x^2\)。
A、B 錯：對摺不會改變開口大小，係數的絕對值仍是 \(5\)，不是倒數。
C 錯：\(5(-x)^2 = 5x^2\)，就是原來的圖形（那是沿 \(y\) 軸對摺的結果）。

重點 4：開口大小——\(|a|\) 愈大，開口愈小

重點整理與敘述

  • 把 \(y = \frac{1}{2}x^2\)、\(y = x^2\)、\(y = 2x^2\) 畫在同一個坐標平面上：係數愈大，圖形往上竄得愈快，開口愈窄。
  • 開口向下時也一樣，只是要比絕對值：\(y = -2x^2\) 的開口比 \(y = -\frac{1}{2}x^2\) 小。
  • 結論：\(|a|\) 愈大，開口愈小；\(|a|\) 愈小，開口愈大。
  • \(a\) 的正負決定開口方向，\(a\) 的絕對值決定開口大小，兩件事分開看。\(|a|\) 相同、正負相反的兩個圖形，開口一樣大、對稱於 \(x\) 軸。
KEY POINT・開口大小 \(|a|\) 愈大 → 開口愈小（愈窄）

形成性評量 (開口大小)

Q7. 甲：\(y = -5x^2\)、乙：\(y = \frac{1}{4}x^2\)、丙：\(y = 4x^2\)、丁：\(y = -\frac{2}{5}x^2\)。四個圖形的開口由大到小排列為何？

解析：答案為 C。比絕對值：\(|a|\) 依序是 \(5\)、\(\frac{1}{4}\)、\(4\)、\(\frac{2}{5}\)，由小到大是 \(\frac{1}{4} \lt \frac{2}{5} \lt 4 \lt 5\)。\(|a|\) 愈小開口愈大，所以乙 \(\gt\) 丁 \(\gt\) 丙 \(\gt\) 甲。
A 錯：排成了開口由小到大。
B 錯：直接比 \(a\) 的大小（\(-5\) 最小）而忘了取絕對值。
D 錯：\(\frac{2}{5} \gt \frac{1}{4}\)，丁的開口比乙小。

Q8. 二次函數 \(y = ax^2\) 的圖形開口向上，而且開口比 \(y = -6x^2\) 的開口大。\(a\) 可能是下列哪一個數？

解析：答案為 A。開口向上 \(\Rightarrow\) \(a \gt 0\)；開口比 \(y = -6x^2\) 大 \(\Rightarrow\) \(|a| \lt 6\)。所以 \(0 \lt a \lt 6\)，只有 \(5\) 符合。
B 錯：\(a \lt 0\)，開口向下。
C 錯：\(|7| \gt 6\)，開口比較小。
D 錯：開口向下，而且開口也比較小。

重點 5：\(y = ax^2 + k\)——上下平移，頂點 \((0, k)\)

重點整理與敘述

  • 同一個 \(x\)，\(y = x^2 + 1\) 的值都比 \(y = x^2\) 多 \(1\)：圖形上每個點都往上移 \(1\) 單位，最低點由 \((0, 0)\) 移到 \((0, 1)\)。
  • \(k \gt 0\)：由 \(y = ax^2\) 向上平移 \(k\) 單位；\(k \lt 0\)：向下平移 \(|k|\) 單位。
  • \(y = ax^2 + k\) 的對稱軸仍是 \(y\) 軸；\(a \gt 0\) 時最低點是 \((0, k)\)，\(a \lt 0\) 時最高點是 \((0, k)\)。
  • 上下平移不改變 \(a\)：開口方向與大小都和 \(y = ax^2\) 一樣。
  • 兩個 \(a\) 相同的圖形也能互相平移：\(y = 3x^2 - 2\) 由 \(y = 3x^2 + 1\) 向下平移 \(3\) 單位，看的是兩個 \(k\) 的差。
KEY POINT・上下平移 \(y = ax^2\) \(\xrightarrow{\text{上下移 } k}\) \(y = ax^2 + k\)，頂點 \((0, k)\)

形成性評量 (上下平移)

Q9. 將 \(y = -\frac{3}{4}x^2\) 的圖形向下平移 \(6\) 單位，會得到哪一個二次函數的圖形？它的最高點或最低點為何？

解析：答案為 B。向下平移 \(6\) 單位，每個 \(y\) 都減 \(6\)：\(y = -\frac{3}{4}x^2 - 6\)。\(a \lt 0\) 開口向下，頂點 \((0, -6)\) 是最高點。
A 錯：加 \(6\) 是向上平移。
C 錯：括號裡減 \(6\) 是向右平移。
D 錯：開口向下，頂點是最高點，不是最低點。

Q10. 二次函數 \(y = 4x^2 - 3\) 的圖形，可以由 \(y = 4x^2 + 5\) 的圖形怎麼平移得到？

解析：答案為 D。兩者的 \(a\) 都是 \(4\)，頂點由 \((0, 5)\) 移到 \((0, -3)\)，\(-3 - 5 = -8\)，是向下平移 \(8\) 單位。
A 錯：方向反了，\(-3\) 比 \(5\) 低。
B 錯：直接拿 \(5 - 3 = 2\)，忽略了 \(-3\) 的負號。
C 錯：只改常數項是上下平移，不是左右平移。

重點 6：\(y = a(x - h)^2\)——左右平移，頂點 \((h, 0)\)

重點整理與敘述

  • \(y = (x - 1)^2\)：括號等於 \(0\) 時 \(y\) 最小，也就是 \(x = 1\) 時。所以最低點是 \((1, 0)\)，圖形以直線 \(x = 1\) 為對稱軸。
  • \(h \gt 0\)：由 \(y = ax^2\) 向右平移 \(h\) 單位；\(h \lt 0\)：向左平移 \(|h|\) 單位。
  • 最容易錯的是符號：\(y = (x + 2)^2 = (x - (-2))^2\)，\(h = -2\)，是向左平移 \(2\) 單位，頂點 \((-2, 0)\)。
  • \(a \gt 0\) 時頂點 \((h, 0)\) 是最低點，\(a \lt 0\) 時是最高點；開口方向與大小都和 \(y = ax^2\) 一樣。
式子\(h\)平移頂點
\(y = 2(x - 1)^2\)\(1\)向右 \(1\)\((1, 0)\)
\(y = 2(x + 2)^2\)\(-2\)向左 \(2\)\((-2, 0)\)

形成性評量 (左右平移)

Q11. 關於 \(y = \frac{2}{3}(x + 7)^2\) 的圖形，下列敘述何者正確？

解析：答案為 A。\(x + 7 = x - (-7)\)，\(h = -7\)，向左平移 \(7\) 單位；括號為 \(0\) 時 \(x = -7\)，最低點 \((-7, 0)\)，對稱軸 \(x = -7\)。
B 錯：看到 \(+7\) 就以為向右，符號弄反了。
C 錯：左右平移改變的是頂點的 \(x\) 坐標，頂點應在 \(x\) 軸上。
D 錯：常數項是 \(0\)，沒有上下平移。

Q12. 將 \(y = -x^2\) 的圖形向右平移 \(6\) 單位，會得到哪一個二次函數的圖形？

解析：答案為 C。向右平移 \(6\) 單位，\(h = 6\)，\(y = -(x - 6)^2\)，最高點由 \((0, 0)\) 移到 \((6, 0)\)。
A 錯：那是向上平移 \(6\) 單位。
B 錯：\((x + 6)^2\) 是向左平移。
D 錯：那是向下平移 \(6\) 單位。

重點 7：\(y = a(x - h)^2 + k\)——拋物線與頂點 \((h, k)\)

重點整理與敘述

  • \(y = a(x - h)^2 + k\) 的圖形，由 \(y = ax^2\) 先左右平移 \(|h|\) 單位、再上下平移 \(|k|\) 單位而得（先上下再左右也一樣）。
  • 投出去的籃球、噴泉的水柱走的路徑，都是二次函數圖形的一部分，所以二次函數的圖形稱為拋物線。
  • 拋物線是線對稱圖形，它與對稱軸的交點稱為頂點：開口向上時頂點是最低點，開口向下時頂點是最高點。
  • \(y = a(x - h)^2 + k\)：頂點 \((h, k)\)、對稱軸是直線 \(x = h\)。例：\(y = -(x - 1)^2 + 4\) 開口向下，頂點 \((1, 4)\) 是最高點。
  • 前面三種都是它的特例：\(y = ax^2\)（\(h = k = 0\)）、\(y = ax^2 + k\)（\(h = 0\)）、\(y = a(x - h)^2\)（\(k = 0\)）。
KEY POINT・頂點式 \(y = a(x - h)^2 + k\)：頂點 \((h, k)\)，對稱軸 \(x = h\)

形成性評量 (頂點與拋物線)

Q13. 二次函數 \(y = -3(x + 6)^2 + 2\) 的圖形，頂點與對稱軸為何？

解析：答案為 D。\(y = -3(x - (-6))^2 + 2\)，\(h = -6\)、\(k = 2\)，頂點 \((-6, 2)\)，對稱軸是通過頂點的鉛垂線 \(x = -6\)。
A 錯：\(x + 6\) 的 \(h\) 是 \(-6\)，不是 \(6\)。
B 錯：\(k\) 是 \(+2\)，不必變號。
C 錯：對稱軸是鉛垂線 \(x = h\)，不是水平線。

Q14. 二次函數 \(y = 2x^2 + 3\) 的圖形，要怎麼平移才能得到 \(y = 2(x - 5)^2 - 4\) 的圖形？

解析：答案為 B。看頂點怎麼移：\((0, 3)\) 移到 \((5, -4)\)。\(x\) 坐標 \(0 \to 5\) 是向右 \(5\)；\(y\) 坐標 \(3 \to -4\)，\(-4 - 3 = -7\)，是向下 \(7\)。
A 錯：起點的頂點在 \((0, 3)\)，不在原點，不能只看 \(-4\)。
C 錯：\((x - 5)^2\) 是向右。
D 錯：把 \(3\) 與 \(-4\) 相加得 \(-1\)；應該相減。

重點 8：與 \(x\) 軸的交點個數——看開口與頂點

重點整理與敘述

  • 不必把圖畫準，只要知道開口方向與頂點在 \(x\) 軸的哪一側，就能約略畫出拋物線，數出它和 \(x\) 軸交幾次。
  • 開口向上、頂點在 \(x\) 軸下方：兩側往上延伸，一定穿過 \(x\) 軸兩次。開口向下、頂點在上方也一樣。
  • 頂點恰好在 \(x\) 軸上（\(k = 0\)）：恰有一個交點，就是頂點。
  • 開口向上、頂點在上方，或開口向下、頂點在下方：整條圖形在 \(x\) 軸的同一側，沒有交點。
  • 例：\(y = 2(x + 1)^2 - 3\) 開口向上、頂點 \((-1, -3)\) 在下方 \(\Rightarrow\) 兩個交點。\(h\) 只決定左右位置，不影響個數。

Q16. 若二次函數 \(y = a(x - 2)^2 - 7\) 的圖形與 \(x\) 軸沒有交點，則 \(a\) 可能是下列哪一個數？

解析：答案為 A。頂點 \((2, -7)\) 在 \(x\) 軸下方；要碰不到 \(x\) 軸，整條圖形必須往下開，所以 \(a \lt 0\)，只有 \(-4\) 符合。
B、C、D 錯：\(a \gt 0\) 時開口向上，最低點在下方，兩側往上一定穿過 \(x\) 軸兩次。開口大小（\(|a|\)）不影響交點個數。

重點 9：最大值與最小值——就是頂點的 \(y\) 坐標

重點整理與敘述

  • 不論 \(x\) 是多少，\((x - h)^2 \ge 0\)。
  • \(a \gt 0\)：\(a(x - h)^2 \ge 0\)，所以 \(y = a(x - h)^2 + k \ge k\)。當 \(x = h\) 時，\(y\) 有最小值 \(k\)。
  • \(a \lt 0\)：乘上負數不等號變向，\(a(x - h)^2 \le 0\)，\(y \le k\)。當 \(x = h\) 時，\(y\) 有最大值 \(k\)。
  • 開口向上只有最小值，沒有最大值；開口向下只有最大值，沒有最小值——圖形往兩側無限延伸。
  • 最大（小）值是 \(y\) 的值 \(k\)，發生在 \(x = h\) 時；別把 \(h\)、\(k\) 或係數 \(a\) 搞混。例：\(y = 3(x - 2)^2 - 1\)，\(x = 2\) 時有最小值 \(-1\)。

Q17. 關於二次函數 \(y = -2(x + 9)^2 + 11\)，下列敘述何者正確？

解析：答案為 B。\(a = -2 \lt 0\)，開口向下，頂點 \((-9, 11)\) 是最高點：\(x = -9\) 時 \(y\) 有最大值 \(11\)。
A 錯：括號是 \(x + 9\)，為 \(0\) 時 \(x = -9\)。
C 錯：開口向下只有最大值，沒有最小值。

Q18. 甲、乙兩個二次函數分別為 \(y = (x - 40)^2 - 25\)、\(y = -(x + 15)^2 - 25\)，下列敘述何者正確？

解析：答案為 D。乙的 \(a = -1 \lt 0\)，開口向下，頂點 \((-15, -25)\) 是最高點，\(x = -15\) 時有最大值 \(-25\)。
A 錯：甲開口向上，只有最小值。

重點 10：由頂點與另一點，求二次函數

重點整理與敘述

  • 已知頂點 \((h, k)\)，就可以直接設 \(y = a(x - h)^2 + k\)，只剩 \(a\) 一個未知數。
  • 再把圖形通過的另一點代入，解一元一次方程式求出 \(a\)。
  • 例：頂點 \((1, 3)\)，通過 \((-1, -5)\)。設 \(y = a(x - 1)^2 + 3\)，代入得 \(-5 = 4a + 3\)，\(a = -2\)，所以 \(y = -2(x - 1)^2 + 3\)。
  • 小心兩件事：頂點是負數時要變號（頂點 \((-4, 1)\) 設成 \(y = a(x + 4)^2 + 1\)）；代入後括號要先平方再乘 \(a\)。
  • 求出的 \(a\) 不可以是 \(0\)；另一點也不能在對稱軸 \(x = h\) 上（除了頂點本身，拋物線在對稱軸上只有頂點一個點）。
KEY POINT・設頂點式 知道頂點 \((h, k)\) → 設 \(y = a(x - h)^2 + k\) → 代另一點求 \(a\)

形成性評量 (求二次函數)

Q19. 有一個二次函數，其圖形的頂點為 \((5, -2)\)，且通過點 \((7, 10)\)。此二次函數為何？

解析：答案為 A。設 \(y = a(x - 5)^2 - 2\)，代入 \((7, 10)\)： \[\begin{aligned} 10 &= a(7 - 5)^2 - 2 \\ 12 &= 4a,\ a = 3 \end{aligned}\] 所以 \(y = 3(x - 5)^2 - 2\)。
B 錯：頂點的 \(x\) 坐標是 \(5\)，括號應是 \(x - 5\)。
C 錯：把 \((7 - 5)^2\) 算成 \(2\)，忘了平方。
D 錯：頂點的 \(y\) 坐標是 \(-2\)，常數項應是 \(-2\)。

Q20. 某二次函數圖形的頂點為 \((0, 8)\)，且與 \(x\) 軸交於點 \((-4, 0)\)。此二次函數與它和 \(x\) 軸的另一個交點為何？

解析：答案為 C。設 \(y = ax^2 + 8\)，代入 \((-4, 0)\)：\(0 = 16a + 8\)，\(a = -\frac{1}{2}\)。對稱軸是 \(y\) 軸，\((-4, 0)\) 的對稱點 \((4, 0)\) 就是另一個交點。
A 錯：把 \((-4)^2\) 算成 \(4\)：\(0 = 4a + 8\) 才會得到 \(a = -2\)。
B 錯：移項時漏了負號；頂點在 \(x\) 軸上方又與 \(x\) 軸相交，開口一定向下。
D 錯：\((0, -4)\) 在 \(y\) 軸上，不是 \(x\) 軸上的點。

重點 11：平移的應用——平移不改變 \(a\)

重點整理與敘述

  • 平移只改變位置，不改變開口方向與大小：由 \(y = ax^2\) 平移得到的圖形，一定是 \(y = a(x - h)^2 + k\)，\(a\) 不變。
  • 題目說「由 \(y = 3x^2\) 平移而得」，就是告訴你 \(a = 3\)；再給對稱軸就知道 \(h\)，最後用通過的點求 \(k\)。
  • 對稱軸常寫成方程式：「對稱軸為直線 \(x - 2 = 0\)」就是 \(x = 2\)，\(h = 2\)。
  • 反過來，\(a\) 相同的兩個二次函數，開口一樣大；常數項不同不代表開口不同。例：\(y = (x - 1)^2 + 2\) 與 \(y = (x - 1)^2 - 4\) 開口一樣大，前者向下平移 \(6\) 單位就與後者重合。
  • 平移的過程中，圖形與 \(y\) 軸的交點是 \((0,\ ah^2 + k)\)：頂點往 \(y\) 軸靠近時 \(h^2\) 變小，越過 \(y\) 軸後又變大，交點會「去了又回」。
KEY POINT・平移 由 \(y = ax^2\) 平移 → \(y = a(x - h)^2 + k\)，\(a\) 不變

形成性評量 (平移的應用)

Q21. 已知二次函數 \(y = a(x - h)^2 + k\) 的圖形可由 \(y = 4x^2\) 的圖形平移得到，其對稱軸為直線 \(x + 1 = 0\)，且圖形通過點 \((1, 9)\)。此圖形的頂點為何？

解析：答案為 B。由 \(y = 4x^2\) 平移 \(\Rightarrow\) \(a = 4\)；對稱軸 \(x = -1\) \(\Rightarrow\) \(h = -1\)。設 \(y = 4(x + 1)^2 + k\)，代入 \((1, 9)\)： \[\begin{aligned} 9 &= 4 \times 2^2 + k \\ k &= 9 - 16 = -7 \end{aligned}\] 頂點為 \((-1, -7)\)。
A 錯：把 \(x + 1 = 0\) 讀成 \(x = 1\)，\((1, 9)\) 就變成頂點了。
C 錯：移項時把 \(16\) 加過去：\(9 + 16 = 25\)。
D 錯：把 \(2^2\) 算成 \(2\)：\(9 = 8 + k\)，\(k = 1\)。

Q22. 坐標平面上有二次函數 \(y = (x - 6)^2 - 10\) 的圖形，今將它向左平移 \(9\) 單位。平移過程中，圖形與 \(y\) 軸的交點 \(P\) 位置如何變化？

解析：答案為 C。平移時頂點由 \((6, -10)\) 往左移到 \((-3, -10)\)，圖形是 \(y = (x - h)^2 - 10\)，\(h\) 由 \(6\) 變到 \(-3\)。\(P\) 的 \(y\) 坐標是 \(h^2 - 10\)：
\(h\) 由 \(6\) 到 \(0\)：由 \(26\) 降到 \(-10\)（向下）；\(h\) 由 \(0\) 到 \(-3\)：由 \(-10\) 升到 \(-1\)（向上）。
A 錯：沒有注意頂點越過了 \(y\) 軸。
B、D 錯：開口向上，頂點在 \(y\) 軸上時 \(P\) 最低，所以是先下後上。

重點 12：對稱性的應用——看離對稱軸多遠

重點整理與敘述

  • 拋物線對稱於 \(x = h\)：離對稱軸一樣遠的兩點，\(y\) 坐標相同。
  • 比較函數值不必一一代入：開口向上，離軸愈遠 \(y\) 愈大；開口向下，離軸愈遠 \(y\) 愈小。
  • 例：\(y = 3(x - 2)^2 + 1\) 上的 \(A(1, a)\)、\(B(2, b)\)、\(C(3, c)\)、\(D(5, d)\)，離 \(x = 2\) 的距離是 \(1\)、\(0\)、\(1\)、\(3\)，開口向上，所以 \(d \gt a = c \gt b\)。
  • 一條水平線和拋物線交於兩點時，兩點高度相同，所以對稱於對稱軸：兩點 \(x\) 坐標的平均就是 \(h\)。
  • 知道一個交點，就能直接寫出另一個：對稱軸 \(x = 2\)，一個交點 \(x = -1\)，另一個是 \(2 \times 2 - (-1) = 5\)。
KEY POINT・對稱 同高的兩點：\(\frac{x_1 + x_2}{2} = h\)

Q24. 二次函數 \(y = a(x - 4)^2 + k\) 的圖形與一條水平線交於 \(A(-3, m)\)、\(B(p, m)\) 兩相異點，則 \(p\) 是多少？

解析：答案為 A。\(A\)、\(B\) 高度相同，對稱於對稱軸 \(x = 4\)：\(\frac{-3 + p}{2} = 4\)，\(p = 11\)。也可以這樣想：\(A\) 在對稱軸左邊 \(7\) 單位，\(B\) 就在右邊 \(7\) 單位。
B 錯：\(7\) 只是 \(A\) 到對稱軸的距離，還要加上 \(4\)。
C 錯：把 \(-3\) 當成距離 \(3\)，算成 \(4 - 3\)。
D 錯：符號弄反了，\(B\) 應在對稱軸右側。

小節總結與核心回顧

二次函數速查表

  • 二次函數：化簡後 \(y = ax^2 + bx + c\)，\(a \ne 0\)；先化簡再判斷。
  • 開口：\(a \gt 0\) 向上、\(a \lt 0\) 向下；\(|a|\) 愈大開口愈小。
  • 平移：\(y = ax^2 + k\) 上下移，\(y = a(x - h)^2\) 左右移；\((x + 2)^2\) 是向左。
  • 頂點式：\(y = a(x - h)^2 + k\)，頂點 \((h, k)\)、對稱軸 \(x = h\)，圖形是拋物線。
  • \(x\) 軸交點：看開口方向與頂點在 \(x\) 軸的哪一側，有 \(2\)、\(1\)、\(0\) 個。
  • 最大最小值：\(x = h\) 時，\(a \gt 0\) 有最小值 \(k\)，\(a \lt 0\) 有最大值 \(k\)。
  • 求函數：知道頂點就設 \(y = a(x - h)^2 + k\)，平移而來的 \(a\) 不變。
  • 對稱：離軸一樣遠的點同高；同高的兩點中點在對稱軸上。

回到球場：這一球的路線

投籃的路徑是拋物線

若以出手處正下方為原點，籃球的水平距離 \(x\) 公尺、高度 \(y\) 公尺，路徑可能是 \(y = -\frac{1}{4}(x - 3)^2 + 5\) 的一部分：開口向下，頂點 \((3, 5)\) 是最高點，球飛到水平 \(3\) 公尺處時最高，高度 \(5\) 公尺。

拋物線也長在農場裡

有機農場搭起拱形的瓜棚，最高點離地 \(3\) 公尺、在水平距離 \(4\) 公尺處，棚子的形狀就可以設成 \(y = a(x - 4)^2 + 3\)——知道頂點，再量一個點就能求出 \(a\)。
