3-1 空間中的線、平面與形體

冰雪節的冰雕工坊裡，小雪和阿磚每天都在和長方體冰磚打交道：冰牆有沒有立直、冰柱的影子落在哪裡、冰杯要用多少冰。七年級學過平面上的圖形，這一節走進空間：先用長方體檢驗垂直、平行與歪斜，再認識角柱、圓柱、角錐、圓錐的組成與展開圖，最後算出它們的體積與表面積。

課前暖身漫畫：冰牆有沒有立直？

阿磚砌好一面冰牆，拍拍手說「看起來很直啊」。小雪沒有用眼睛看，而是拿一塊長方體冰磚平放在地上、推過去貼著牆——冰磚和牆之間，露出了一道細細的縫。長方體為什麼能拿來檢查「垂直」？這一節就從這塊冰磚開始。

重點 1：用長方體檢驗垂直——平面、直線都能驗

重點整理與敘述

  • 長方體有三個好用的性質：相鄰的面互相垂直、底面與高互相垂直、相交於同一端點的邊互相垂直。空間中的垂直，就用長方體來檢驗。
  • 平面與平面：把長方體的底面平放在平面 \(S\) 上，推近平面 \(T\)：
    • 側面能和 \(T\) 緊密貼合 \(\Rightarrow\) 兩平面互相垂直，記為 \(S \perp T\)。
    • 貼不緊、留下空隙 \(\Rightarrow\) 兩平面不垂直。
  • 直線與平面：長方體放在 \(S\) 上，它的一條高能和直線 \(L\) 緊密貼合 \(\Rightarrow\) \(L \perp S\)（也可記為 \(S \perp L\)）。
  • 直線與直線：兩相交直線 \(L\)、\(M\) 能分別和長方體相鄰的兩條邊完全貼合 \(\Rightarrow\) \(L \perp M\)。
  • 例：門和地板互相垂直；埃及金字塔的側面斜靠著，和底面不垂直。
檢驗工具 長方體：相鄰的面 \(\perp\)、高 \(\perp\) 底面、同一端點的邊 \(\perp\)

形成性評量 (用長方體檢驗垂直)

Q1. 冰雕師傅刻了一座正四角錐形狀的冰金字塔。下列哪一組互相垂直？

解析：答案為 C。正角錐的錐頂與底面正方形中心的連線（角錐的高）與底面垂直：長方體平放在底面上，它的高可以和這條連線貼合。
A 錯：側面斜斜地靠向錐頂，長方體推過去，上緣先碰到側面、下方留下空隙。
B 錯：兩個側面都是斜的，也貼不緊長方體相鄰的兩面。
D 錯：側邊從底面的角斜斜地伸向錐頂，和長方體的高貼不合。

Q2. 下圖是長方體 \(ABCD\)-\(EFGH\)（上底 \(ABCD\)、下底 \(EFGH\)）。下列哪一個平面與 \(\overline{AE}\) 垂直？

解析：答案為 B。\(\overline{AE}\) 是長方體的高，高與底面互相垂直，所以 \(\overline{AE} \perp\) 平面 \(EFGH\)。
A、D 錯：\(\overline{AE}\) 就在平面 \(ABFE\)、平面 \(ADHE\) 上，不是垂直。
C 錯：\(\overline{AE}\) 和平面 \(BCGF\) 不相交，是平行（重點 3）。

重點 2：直線垂直平面——通過交點的每一條線都垂直

重點整理與敘述

  • 直線 \(L\) 垂直平面 \(S\)，交點為 \(P\)：可以找到一個長方體，底面貼著 \(S\)、高貼著 \(L\)。
  • \(S\) 上另一條通過 \(P\) 的直線 \(M\)：把長方體繞著 \(L\) 旋轉，讓底邊貼住 \(M\)；長方體通過同一頂點的邊互相垂直，所以 \(L \perp M\)。
  • 結論：若 \(L \perp S\)、交點為 \(P\)，則平面 \(S\) 上通過 \(P\) 點的任一條直線都與 \(L\) 垂直。
  • 例：電線杆與地面垂直，杆子的影子落在地面上、而且通過杆腳，所以影子與電線杆互相垂直。
  • 注意：
    • \(S\) 上不通過 \(P\) 的直線和 \(L\) 根本不相交，不說它們垂直。
    • \(L\) 只要是斜的，\(S\) 上通過 \(P\) 的直線就不會全部和 \(L\) 垂直。
線垂直面 \(L \perp S\)（交於 \(P\)）\(\Rightarrow\) \(S\) 上通過 \(P\) 的每一條直線都 \(\perp L\)

形成性評量 (直線垂直平面)

Q3. 一根旗桿垂直立在操場上，桿腳為 \(P\) 點。操場上畫了三條通過 \(P\)、方向各不相同的白線 \(X\)、\(Y\)、\(Z\)。下列敘述何者正確？

解析：答案為 C。旗桿垂直於地面，交點是 \(P\)；地面上通過 \(P\) 的任一條直線都與旗桿垂直，和白線的方向無關。
A、B 錯：不論白線轉到哪個方向，長方體繞著旗桿轉，底邊都能貼住它。
D 錯：白線本身不必是長方體的邊；長方體只是檢驗的工具。

Q4. 直線 \(L\) 與平面 \(S\) 垂直，交點為 \(P\)。平面 \(S\) 上另有一條直線 \(M\)，\(M\) 不通過 \(P\) 點。\(L\) 與 \(M\) 是什麼關係？

解析：答案為 C。\(L\) 和平面 \(S\) 只交在 \(P\) 點，\(M\) 在 \(S\) 上卻不通過 \(P\)，所以 \(L\) 與 \(M\) 不相交；\(L\) 又不會和 \(S\) 上的直線平行，兩線不在同一平面上，是歪斜關係。
A、D 錯：兩線根本沒有交點。
B 錯：\(L\) 垂直於 \(S\)，不可能和 \(S\) 上的直線平行。

重點 3：平行——同時垂直於同一條直線

重點整理與敘述

  • 平面與平面：如果能找到一條直線同時垂直於兩個平面，就說這兩個平面互相平行。
    • 長方體中，\(\overline{CG}\) 同時垂直於平面 \(ABCD\) 與平面 \(EFGH\)，記為平面 \(ABCD\) \(//\) 平面 \(EFGH\)。
    • 這條直線夾在兩平面間的線段長，叫做兩平面的距離。
  • 直線與平面：直線不在平面上，又和某條垂直於這個平面的直線互相垂直，就說直線與平面平行。
    • 長方體中，\(\overline{AB}\) 不在平面 \(EFGH\) 上，\(\overline{BF}\) 同時垂直於 \(\overline{AB}\) 與平面 \(EFGH\)，所以 \(\overline{AB}\) \(//\) 平面 \(EFGH\)。
  • 長方體：相對的兩個面互相平行、相鄰的兩個面互相垂直。
平行的判斷 同一條直線同時垂直兩平面 \(\Rightarrow\) 兩平面平行

形成性評量 (平行)

Q5. 下圖是長方體 \(ABCD\)-\(EFGH\)。下列哪一條邊與平面 \(BCGF\) 平行？

解析：答案為 B。\(\overline{AD}\) 不在平面 \(BCGF\) 上；\(\overline{AB}\) 垂直於平面 \(BCGF\)，又和 \(\overline{AD}\) 互相垂直，所以 \(\overline{AD}\) \(//\) 平面 \(BCGF\)。（也可以看成：\(\overline{AD}\) 在對面的平面 \(ADHE\) 上，兩個面互相平行。）
A、D 錯：\(\overline{AB}\)、\(\overline{EF}\) 都和平面 \(BCGF\) 垂直。
C 錯：\(\overline{CG}\) 就在平面 \(BCGF\) 上。

Q6. 在上圖的長方體中，\(\overline{BF}\) 同時垂直於 \(\overline{FG}\) 與平面 \(ABCD\)，而 \(\overline{FG}\) 不在平面 \(ABCD\) 上。由此可以知道什麼？

解析：答案為 D。直線不在平面上，又和一條垂直於這個平面的直線（\(\overline{BF}\)）互相垂直，就是直線與平面平行：下底的邊 \(\overline{FG}\) 和上底面平行。
A 錯：垂直於平面 \(ABCD\) 的是 \(\overline{BF}\)，不是 \(\overline{FG}\)。
B 錯：\(B\) 是 \(\overline{BF}\) 的端點，不在 \(\overline{FG}\) 上；\(\overline{FG}\) 和平面 \(ABCD\) 碰不到。
C 錯：題目已說 \(\overline{FG}\) 不在平面 \(ABCD\) 上，它在下底 \(EFGH\)。

重點 4：兩直線——相交、平行，還是歪斜？

重點整理與敘述

  • 空間中的兩條直線有三種關係：
    • 相交：有一個交點（一定在同一個平面上）。
    • 平行：不相交，而且在同一個平面上。例：長方體中 \(\overline{AB} // \overline{CD}\)；\(\overline{AB}\) 與 \(\overline{GH}\) 都在長方形 \(ABGH\) 上，所以 \(\overline{AB} // \overline{GH}\)。
    • 歪斜：不相交，也不在同一個平面上。例：長方體中 \(\overline{BC}\) 與 \(\overline{DH}\)、\(\overline{BC}\) 與 \(\overline{EF}\)。
  • 平面上的兩條線「不相交就平行」；到了空間，不相交還要再看在不在同一個平面上。
  • 四個面都是正三角形的三角錐叫做正四面體。它的六條邊沒有任何兩條平行，例如 \(\overline{BC}\) 與 \(\overline{AD}\) 是歪斜關係。
  • 評量以長方體與正四面體為主。
兩直線 不相交 \(+\) 同平面 \(=\) 平行；不相交 \(+\) 不同平面 \(=\) 歪斜

形成性評量 (相交、平行與歪斜)

Q7. 下圖是一座冰雕的正四角錐 \(O\)-\(ABCD\)，底面 \(ABCD\) 是正方形。下列哪一條直線與 \(\overline{BC}\) 是歪斜關係？

解析：答案為 C。\(\overline{OD}\) 和 \(\overline{BC}\) 沒有共同的點，也找不到一個平面同時包含它們，是歪斜關係。
A 錯：\(\overline{AD}\) 和 \(\overline{BC}\) 是正方形的對邊，在同一平面上且不相交，互相平行。
B、D 錯：\(\overline{OB}\) 和 \(\overline{BC}\) 交於 \(B\)，\(\overline{CD}\) 和 \(\overline{BC}\) 交於 \(C\)，都是相交。

Q8. 關於正四面體 \(ABCD\) 的 6 條邊，下列敘述何者正確？

解析：答案為 B。以 \(\overline{AB}\) 為例：\(\overline{AC}\)、\(\overline{AD}\) 交於 \(A\)，\(\overline{BC}\)、\(\overline{BD}\) 交於 \(B\)，剩下的 \(\overline{CD}\) 和它沒有共同端點、也不在同一平面上，是歪斜。每一條邊都是這樣，只對到「對面」的那一條。
A 錯：正四面體沒有平行的邊。
C 錯：\(\overline{AB}\) 與 \(\overline{CD}\) 不相交。
D 錯：和 \(\overline{AB}\) 歪斜的只有 \(\overline{CD}\) 一條。

重點 5：角柱的組成——頂點 \(2n\)、面 \(n + 2\)、邊 \(3n\)

重點整理與敘述

  • 角柱：由上下兩個全等且平行的多邊形底面，和一些平行四邊形的側面組成。底面是 \(n\) 邊形，就叫 \(n\) 角柱。
  • 側面與底面垂直的叫直角柱，它的側面都是長方形；直角柱的底面是正多邊形時，叫正角柱。國中只討論直角柱，沒有特別說明時，角柱都指直角柱。
  • 兩個底面的距離叫做角柱的高；每個底面的面積叫做底面積。
  • 數一數 \(n\) 角柱：
    • 頂點：上、下底各 \(n\) 個，共 \(2n\) 個。
    • 面：兩個底面 \(+\) \(n\) 個側面，共 \(n + 2\) 個。
    • 邊：上、下底各 \(n\) 條 \(+\) \(n\) 條側邊，共 \(3n\) 條。
  • 例：七角柱有 \(14\) 個頂點、\(9\) 個面、\(21\) 條邊。
角柱頂點面邊
三角柱\(6\)\(5\)\(9\)
四角柱\(8\)\(6\)\(12\)
\(n\) 角柱\(2n\)\(n + 2\)\(3n\)

形成性評量 (角柱的組成)

Q9. 某個角柱共有 \(36\) 條邊，它有幾個頂點？

解析：答案為 C。\(n\) 角柱有 \(3n\) 條邊，\(3n = 36\)，\(n = 12\)，是十二角柱，頂點有 \(2n = 24\) 個。
A 錯：\(12\) 是底面的邊數 \(n\)。
B 錯：\(14 = n + 2\) 是面數。
D 錯：\(38\) 是把邊數加 \(2\)，沒有先求出 \(n\)。

Q10. 某個角柱的頂點數與面數加起來是 \(47\)，它有幾條邊？

解析：答案為 A。頂點 \(2n\)、面 \(n + 2\)，\(2n + (n + 2) = 3n + 2 = 47\)，\(n = 15\)，邊有 \(3n = 45\) 條。
B 錯：\(30 = 2n\) 是頂點數。
C 錯：\(17 = n + 2\) 是面數。
D 錯：邊數不等於頂點數加面數，要先求出 \(n\)。

重點 6：角柱的展開圖——摺回去會是什麼樣子？

重點整理與敘述

  • 沿著立體圖形的一些邊剪開、攤平，得到的平面圖形叫做展開圖。同一個立體圖形，剪法不同就有不同的展開圖。
  • 正立方體的展開圖共有 \(11\) 種。六個正方形排成「田」字形的 \(2 \times 2\)、或一排超過四片，摺起來都會重疊，不是展開圖。
  • 判斷時，在腦中（或動手）把每一片沿著共用的邊摺起來，看會不會剛好圍成立體、沒有重疊也沒有缺面。
  • 角柱的展開圖：側面的長方形接成一排，兩個底面接在兩側；互相疊合的邊必須等長。例如三角柱的側面長方形寬度，要分別等於底面三角形的三邊。
檢查展開圖 摺回去：不重疊、不缺面、疊合的邊等長

形成性評量 (展開圖)

Q11. 把下面的展開圖摺成正立方體後，與「甲」相對（互相平行）的是哪一面？

解析：答案為 D。中間一排的乙、丙、丁、戊捲起來圍成一圈，成為四個側面；甲接在這一圈的上緣、己接在下緣，一個當蓋子、一個當底，所以甲與己相對。
A 錯：乙和甲共用一條邊，摺好後相鄰（垂直）。
B、C 錯：丙、丁都在那一圈側面上，和蓋子甲都相鄰。

Q12. 一個直三角柱的展開圖中，甲、乙是兩個三角形，丙是一個長方形。把它摺成直三角柱後，下列敘述何者正確？

解析：答案為 B。三角柱的兩個三角形是上下兩個底面，兩底面互相平行；長方形是側面，直角柱的側面與底面垂直。
A、D 錯：側面丙和底面甲相交於一條邊，不會平行。
C 錯：甲、乙是相對的兩個底面，不相交，是平行。

重點 7：角柱的體積與表面積

重點整理與敘述

  • 體積 \(=\) 底面積 \(\times\) 高：三角柱、四角柱在小學學過；五角柱、六角柱可以切成幾個三角柱，體積也是底面積 \(\times\) 高。任意角柱都適用。
  • 表面積 \(=\) 側面的面積和 \(+\) 兩底面積和，也就是展開圖的面積。
  • 直角柱的側面攤開是一個大長方形：長 \(=\) 底面周長、寬 \(=\) 高，所以 \[ \text{側面積} = \text{底面周長} \times \text{高} \]
  • 例：底面是平行四邊形（底 \(9\)、高 \(5\)、另一邊 \(7\)），柱高 \(3\)： \[ \begin{aligned} & \text{體積} = 9 \times 5 \times 3 = 135 \\ & \text{表面積} = 32 \times 3 + 2 \times 45 \\ &\qquad = 186 \end{aligned} \] 底面的高 \(5\) 用來算底面積；側面要用底面的邊長 \(9\)、\(7\) 算周長 \(32\)。
角柱 體積 \(=\) 底面積 \(\times\) 高；表面積 \(=\) 周長 \(\times\) 高 \(+ 2 \times\) 底面積

形成性評量 (角柱的體積與表面積)

Q13. 一塊直三角柱形的冰，底面是兩股 \(7\)、\(24\) 公分，斜邊 \(25\) 公分的直角三角形，柱高 \(5\) 公分。這塊冰的表面積是多少平方公分？

解析：答案為 D。 \[ \begin{aligned} & \text{底面積} = 7 \times 24 \div 2 = 84 \\ & \text{側面積} = (7 + 24 + 25) \times 5 \\ &\qquad = 280 \\ & \text{表面積} = 280 + 2 \times 84 \\ &\qquad = 448 \end{aligned} \] A 錯：周長漏了斜邊 \(25\)，\((7 + 24) \times 5 + 168 = 323\)。
B 錯：只加了一個底面，\(280 + 84 = 364\)。
C 錯：\(84 \times 5 = 420\) 是體積。

Q14. 一個直角柱的底面是梯形，上底 \(4\) 公分、下底 \(10\) 公分、高 \(6\) 公分，角柱的高是 \(8\) 公分。它的體積是多少立方公分？

解析：答案為 A。底面積 \(= (4 + 10) \times 6 \div 2 = 42\)，體積 \(= 42 \times 8 = 336\)。
B 錯：梯形面積忘了除以 \(2\)，\(84 \times 8 = 672\)。

重點 8：長方體裡的最短距離——畢氏定理用兩次

重點整理與敘述

  • 兩點之間直線最短：在長方體裡從 \(B\) 飛到 \(H\)，最短的路線就是線段 \(\overline{BH}\)。
  • \(\overline{BH}\) 不在任何一個面上，要分兩步，每一步都找一個直角三角形：
    • 第一步：底面的直角 \(\triangle FGH\)（\(\angle FGH = 90^\circ\)），求出底面對角線 \(\overline{FH}\)。
    • 第二步：直立的直角 \(\triangle BFH\)（\(\overline{BF}\) 垂直底面，所以 \(\angle BFH = 90^\circ\)），求出 \(\overline{BH}\)。
  • 合起來： \[ \overline{BH} = \sqrt{\text{長}^2 + \text{寬}^2 + \text{高}^2} \]
  • 例：長 \(6\)、寬 \(2\)、高 \(3\)：\(\overline{FH}^2 = 36 + 4 = 40\)，\(\overline{BH}^2 = 40 + 9 = 49\)，\(\overline{BH} = 7\)。
長方體的對角線 \(\sqrt{\text{長}^2 + \text{寬}^2 + \text{高}^2}\)

重點 9：圓柱的展開圖——長方形的長是底圓周長

重點整理與敘述

  • 圓柱的兩個底面是半徑相等且平行的圓。兩個底圓圓心的連線與底面垂直的，叫做直圓柱；國中只討論直圓柱。
  • 把圓柱的側面沿著一條直的邊剪開攤平，得到一個長方形：
    • 長方形的長 \(=\) 底圓的周長 \(2\pi r\)（剛好繞底圓一圈）。
    • 長方形的寬 \(=\) 圓柱的高。
  • 所以圓柱的展開圖是「一個長方形 \(+\) 兩個圓」。判斷一張圖是不是圓柱的展開圖，要檢查長方形的那一邊是不是等於 \(2\pi r\)。
  • 例：底圓半徑 \(2\)，側面長方形的長是 \(2\pi \times 2 = 4\pi\)；長方形的長寫成 \(3\pi\)，就圍不起來。
圓柱的側面 長方形：長 \(= 2\pi r\)、寬 \(= h\)

重點 10：圓柱的體積與表面積

重點整理與敘述

  • 把圓柱切成很多等分、重新拼起來，愈分愈細就愈接近一個四角柱，所以圓柱也是體積 \(=\) 底面積 \(\times\) 高： \[ V = \pi r^2 h \] 任何柱體（角柱與圓柱）都是底面積 \(\times\) 高。
  • 表面積就是展開圖的面積： \[ \begin{aligned} & \text{表面積} = \text{底圓周長} \times \text{高} \\ &\qquad + \text{兩底圓面積} \\ &\quad = 2\pi r h + 2\pi r^2 \end{aligned} \]
  • 把 \(\pi\) 當成一個數，\(2 \times \pi\) 簡寫成 \(2\pi\)；答案保留 \(\pi\) 就好。
  • 例：\(r = 2\)、\(h = 7\)：體積 \(= 4\pi \times 7 = 28\pi\)，表面積 \(= 28\pi + 8\pi = 36\pi\)。
  • 只給展開圖時，先由「長方形的長 \(= 2\pi r\)」求出半徑。
圓柱 \(V = \pi r^2 h\)；表面積 \(= 2\pi r h + 2\pi r^2\)

重點 11：空心與組合的圓柱

重點整理與敘述

  • 空心的杯子（筆筒）：外圈半徑 \(R\)、外壁高 \(H\)，內圈半徑 \(r\)、內壁深 \(d\)。
    • 體積 \(=\) 外側圓柱 \(-\) 挖空的部分 \(= \pi R^2 H - \pi r^2 d\)。
    • 表面積包含外側面、內側面、外底面、上緣的環形、內部的底面。把內底面「搬」到上緣，剛好補成一個完整的大圓： \[ \begin{aligned} & \text{表面積} = 2\pi R H + 2\pi r d \\ &\qquad + 2 \times \pi R^2 \end{aligned} \]
  • 中空的管子（兩端都開口）：體積 \(= \pi (R^2 - r^2) \times\) 長。
  • 兩個圓柱疊在一起：重疊的那塊不算表面積。小圓柱的上底剛好補回大圓柱被遮住的部分，所以表面積 \(=\) 大圓柱的表面積 \(+\) 小圓柱的側面積。也可以把兩個表面積加起來，再扣掉重疊的兩塊圓。
先拆再算 體積：加加減減；表面積：一面一面數，重疊的不算

重點 12：角錐的組成與展開圖

重點整理與敘述

  • \(n\) 角錐：以一個 \(n\) 邊形當底面，加上 \(n\) 個共頂點的三角形當側面，所圍出的立體圖形。
  • 正角錐：底面是正多邊形，側面都是全等的等腰三角形；錐頂與底面中心的連線和底面垂直。國中只討論正角錐。
  • 數一數 \(n\) 角錐：
    • 頂點：底面 \(n\) 個 \(+\) 錐頂 \(1\) 個 \(= n + 1\)。
    • 面：底面 \(1\) 個 \(+\) 側面 \(n\) 個 \(= n + 1\)。
    • 邊：底面 \(n\) 條 \(+\) 側邊 \(n\) 條 \(= 2n\)。
  • 展開圖常見的畫法：底面放中間，側面三角形圍在四周（展開圖不只一種）。每個側面三角形的底邊要等於底面的邊長，而且三角形要夠高，摺起來頂點才會合得起來。
  • 例：六角錐有 \(7\) 個頂點、\(7\) 個面、\(12\) 條邊。
\(n\) 角錐 頂點 \(n + 1\)、面 \(n + 1\)、邊 \(2n\)

重點 13：角錐的表面積——斜高不是錐高

重點整理與敘述

  • 角錐的表面積就是展開圖的面積：表面積 \(=\) 側面三角形的面積和 \(+\) 底面積。
  • 正四角錐（底邊 \(a\)）：側面三角形的高叫做斜高， \[ \begin{aligned} & \text{表面積} \\ & = a^2 + 4 \times \frac{1}{2} \times a \times \text{斜高} \end{aligned} \]
  • 錐高（錐頂到底面中心）、底邊的一半、斜高圍成一個直角三角形，斜高是斜邊。題目只給錐高時，先用畢氏定理求斜高。
  • 正三角形（邊長 \(a\)）：高 \(= \frac{\sqrt{3}}{2}a\)、面積 \(= \frac{\sqrt{3}}{4}a^2\)。四個面都是正三角形的正四面體，表面積 \(= \sqrt{3}a^2\)。
  • 例：底邊 \(8\)、斜高 \(5\) 的正四角錐，表面積 \(= 64 + 4 \times 20 = 144\)。
  • 角錐的體積不是這一節的學習目標。
正四角錐 表面積 \(= a^2 + 2a \times\) 斜高

重點 14：圓錐的展開圖——扇形的弧長是底圓周長

重點整理與敘述

  • 圓錐有一個圓形的底面、一個頂點和側面。頂點與底圓圓心的連線垂直於底面的，叫做直圓錐。
  • 圓錐的展開圖是一個扇形（側面）加一個圓（底面）：
    • 扇形的半徑 \(R\) \(=\) 圓錐的母線（頂點到底圓周上的距離）。
    • 扇形的弧長 \(=\) 底圓的周長 \(2\pi r\)。
  • 弧長是整個圓周的幾分之幾，圓心角就是 \(360^\circ\) 的幾分之幾： \[ \begin{aligned} & \text{圓心角} = 360^\circ \times \frac{2\pi r}{2\pi R} \\ &\qquad = 360^\circ \times \frac{r}{R} \end{aligned} \]
  • 例：\(r = 3\)、\(R = 9\)，圓心角 \(= 360^\circ \times \frac{3}{9} = 120^\circ\)。反過來，知道圓心角與其中一個半徑，也能求另一個半徑。
圓錐展開圖 弧長 \(= 2\pi r\)；圓心角 \(= 360^\circ \times \frac{r}{R}\)

C 錯：\(26\) 是底圓的直徑。
D 錯：用了 \(100^\circ\)（剪掉的部分）去算，\(13 \times \frac{360}{100}\)。

重點 15：圓錐的表面積——扇形加底圓

重點整理與敘述

  • 圓錐的表面積就是展開圖的面積： \[ \text{表面積} = \text{扇形面積} + \text{底圓面積} \]
  • 弧長是整個圓周的 \(\frac{r}{R}\)，扇形面積也是整個圓面積的 \(\frac{r}{R}\)： \[ \text{扇形面積} = \pi R^2 \times \frac{r}{R} = \pi R r \]
  • 所以 \(\text{表面積} = \pi R r + \pi r^2\)（\(R\) 是母線、\(r\) 是底圓半徑）。
  • 題目給的是圓錐的高 \(h\) 時，高、底圓半徑、母線圍成直角三角形，先求母線 \(R = \sqrt{r^2 + h^2}\)。
  • 例：\(r = 3\)、\(R = 5\)：扇形面積 \(= 15\pi\)，表面積 \(= 15\pi + 9\pi = 24\pi\)。
圓錐 表面積 \(= \pi R r + \pi r^2\)

形成性評量 (圓錐的表面積)

Q29. 一個圓錐形的冰雕，底圓半徑 \(9\) 公分、母線長 \(20\) 公分。它的表面積是多少平方公分？

解析：答案為 D。扇形面積 \(= \pi \times 20 \times 9 = 180\pi\)，底圓面積 \(= 81\pi\)，表面積 \(= 180\pi + 81\pi = 261\pi\)。
A 錯：\(180\pi\) 只是側面，沒有加底圓。
B 錯：把側面當成整個半徑 \(20\) 的圓 \(400\pi\)。
C 錯：把扇形面積算成 \(2\pi R r\)。

Q30. 一個圓錐的展開圖中，扇形的半徑是 \(17\)，底圓的半徑是 \(4\)。扇形面積與底圓面積的比是多少？

解析：答案為 A。扇形面積 \(= \pi \times 17 \times 4 = 68\pi\)，底圓面積 \(= 16\pi\)，比 \(= 68 : 16 = 17 : 4\)（就是 \(R : r\)）。
B 錯：把整個半徑 \(17\) 的圓 \(289\pi\) 拿來比。
C 錯：前後項寫反了。
D 錯：\(34 : 16\) 是把扇形面積算成 \(\pi R r \div 2\)。

小節總結與核心回顧

空間與形體速查表

  • 垂直：用長方體檢驗；\(L \perp S\) 時，\(S\) 上通過交點的每一條直線都 \(\perp L\)。
  • 平行：同一條直線同時垂直兩平面 \(\Rightarrow\) 兩平面平行。
  • 兩直線：相交；不相交且同平面 \(\to\) 平行；不相交且不同平面 \(\to\) 歪斜。
  • \(n\) 角柱：頂點 \(2n\)、面 \(n + 2\)、邊 \(3n\)；\(n\) 角錐：頂點 \(n + 1\)、面 \(n + 1\)、邊 \(2n\)。
  • 柱體：體積 \(=\) 底面積 \(\times\) 高；表面積 \(=\) 側面積 \(+\) 兩底面積。
  • 圓柱：側面長方形的長 \(= 2\pi r\)；圓錐：扇形弧長 \(= 2\pi r\)，表面積 \(= \pi R r + \pi r^2\)。

回到冰雕工坊

冰牆立直了嗎？

長方體冰磚相鄰的兩面互相垂直：平放在地上、推過去和冰牆整面貼緊，冰牆才和地面垂直。

斜著拉的燈串

燈串從展示櫃的一角拉到最遠的另一角，不在任何一面上——先在底面找直角三角形，再立起來找第二個，畢氏定理用兩次。

包裝紙要剪多大？

圓柱的包裝紙是長 \(2\pi r\) 的長方形，圓錐的是弧長 \(2\pi r\) 的扇形。先把立體「攤平」，表面積就變成平面圖形的面積。
